# Related portfolio projects

LogLens is one part of a defensive security and IT operations toolkit:

- [SentinelKit](https://github.com/REV3R5ED/SentinelKit) — IOC extraction, IP inspection, file hashing, and authentication-log triage for Blue Team/SOC workflows.
- [NetScope](https://github.com/REV3R5ED/NetScope) — defensive network visibility and bounded diagnostics for operators and security engineers.
- [AutoOPS](https://github.com/REV3R5ED/AutoOPS) — safe, observable IT operations automation with health gates, artifact validation, dry-run controls, and audit-friendly output.
- [LogLens](https://github.com/REV3R5ED/LogLens) — deterministic log analysis, explainable anomaly detection, and reproducible reporting.

The projects are intentionally complementary: use SentinelKit for indicator and authentication triage, NetScope for network diagnostics, AutoOPS for operational checks and automation, and LogLens for log analysis and anomaly triage.
