# LogLens v0.3.0

LogLens v0.3.0 is the portfolio release for the project's expanded defensive analysis workflow after v0.2.0.

## Highlights

- Source-aware error-burst detection with deterministic sliding time windows.
- CLI controls for burst threshold and window size, with effective configuration preserved in machine-readable reports.
- Source-scoped repeated-message analysis to reduce cross-service false positives.
- Per-source health summaries for event volume, error counts, error rate, and level distribution.
- Broader structured-log compatibility, including common OpenTelemetry and ECS fields.
- Safer analyst-facing output, including control-character escaping and CSV formula-injection hardening.
- Deterministic UTC time-window baselines, explainable anomaly scores, and reusable JSON/CSV reporting.

## Safety boundary

LogLens is read-only defensive tooling. It parses and analyzes supplied log data; it does not execute log content, perform exploitation, collect credentials, establish persistence, or mutate monitored systems.

## Validation

The release boundary is covered by a version-contract regression test that requires the runtime version and installed package metadata to remain synchronized. The existing test suite covers parsing, detection, reporting, CLI behavior, source analysis, malformed input, and operational-error handling.
